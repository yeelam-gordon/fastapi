Experimental source: **no CI performance measurements or parity claim**.
The fourteenth manual route is isolated; the original thirteen routes and all
defaults are unchanged. Admission requires a source-bound parent review receipt;
the static plan and mocks do not grant it.

## End-to-end entrypoints

`execution.py prepare --source CHECKOUT --output NEW --uv UV --workers N
--seconds REMAINING` owns the existing common82 bootstrap, exact platform-wheel
provenance, ujson-last reinstall and backend hash. It creates four fresh complete
tracked local-object sources, existing five fixture modifications and the frozen
ExitStack overlay. Each payload has fresh source-only owned helper copies.
No application/test pycs are relocated or preloaded.

`execution.py run` with the same arguments owns the whole controller. Its
`orchestrate` runs A1/B1/B2/A2, exactly one full uv sdist then wheel-from-sdist
and full covered test command per payload, without retries or warmups. Build
uses the prepared wheel directory offline and existing PDM constraints.
`owned` uses the unchanged qualified guardian
45d6db4f6452c4f7116ca23c6e2aa74cda90a15548bd5c9bb3b3574973ef458e.
Remaining-aware commands reserve 120 seconds for final audit; the final audit
has its own owned process and hard cap of min(120, remaining).

`matched_audit.cheap` checks canonical cases/outcomes, captured-object resource
proofs, source/helper hashes, declared source outputs and native PID filenames
after each test. `full` checks immutable SHA-bound native copies, their stored
streaming stamps, all 863 files/1409 contexts and entire raw associations,
real CLI flushes, RECORD and full 1196/58 archive inventories against the
qualified reference plus exactly one frozen fixture member change.
After B1, both first-pair maps/inventories are compared; mismatch stops before
B2. `final` reuses SHA-bound first-pair proofs, parses the remaining two once,
compares all four complete maps/inventories, and checks final source/runtime
preservation inside the bounded audit. Original installed files and caches are
immutable; new dependency pycs require a corresponding immutable installed
source. Fresh helper/source pycs are declared generated outputs, not inputs.

`matched_policy` installs only an early owned-pytest public policy. Windows
default workers select the byte-frozen 77ed prototype for B; main-thread and
explicit constructors stay stock. Mac A/B use stock SelectorEventLoop/Kqueue
semantics, with identical observer subclasses on workers. Unmodified close
returns before certificates inspect strong captured objects, closed sockets,
fd -1/io_refs 0 and proactor/selector closure. No freed numeric ID polling or
instant kernel-reclamation claim. Global resource counts remain UNKNOWN.
The canonical CLI test's Popen is observed only around that test, returning the
original actual Popen object unchanged. PID/object/wait/argv records are bound
to native CLI flushes in its unique owned payload namespace; no Mac birth claim.
Coverage get_data/save/stop are never called by observers.

`provenance.source_contract` verifies retained exact public CPython v3.13.15
source and native kqueue close/closed implementation. `mac_runtime` compares
installed method ASTs and checks an actual captured Kqueue close **only in the
same bounded pre-payload readiness command**. No separate probe/job exists.
`readiness` verifies exact common82 packages, platform-native CTracer against
the existing hash-locked platform wheel, CPU count and interpreter identity.
No Mac runtime acceptance has been performed during source preparation.

`within_host` reports both ordered build/test/sum gaps and the .5-second/1%
Windows threshold with no covered-test timing regression.
`comparison.py --windows EXTRACTED --macos EXTRACTED --output REPORT` consumes
both validated host artifacts and reports position-matched B build/test/total
gaps plus every canonical per-case setup/call/teardown duration gap. It never
compares raw coverage across operating systems. Physical parity/adoption remain
false even when the finite timing thresholds pass.

## Admission and evidence boundaries

Every execution CLI action requires owned fork/attempt one and a parent-created
`PARENT-REVIEW.json` with `approved: true` and `sourcepins_sha256` matching the
current SOURCEPINS file. Every listed source is checked before work. No flag
waives missing review. The workflow uses Windows uv-managed 3.13.15 with
no-bin/no-registry and Mac setup-python arm64 3.13.15, an eight-minute job
allocation, full package checkout and sparse tooling-only checkout.
Server HTTP Date/explicit UTC and actual job state use the existing queue-clock
helper. `queue_readiness.ps1` never cancels. The separate `watch_ci.ps1`
binds cancellation to the exact owned repository, workflow, current branch,
commit SHA, attempt and run ID. It uses server UTC, rejects a queued job beyond
300 seconds and never redispatches. Its finite metadata watch has 32 polls.
Original predecessor evidence remains reference-only in `queue-prior-art`.

Static tests use mocked phases/processes only. Ruff excludes immutable
qualified-fixture.py data and the vendored exact-tag CPython sources; their
syntax/bytes are checked separately. Do not edit frozen prototype/fixture bytes;
the prefix has scoped `-text`.

Required acceptance includes actual Mac runtime/native wheel availability,
service-host execution and source-bound parent review, not a bypassable
performance gate. Current source approval is recorded separately in the
parent receipt; it does not assert service-host or Mac runtime success.
Local full-HOBL proof remains local: original controller audit CLOSED at 60s;
the independent 52.904s qualifier does not rewrite it or turn forced audit cleanup
into natural drainage. Local 4LP is not physical/Mac evidence. Common82 CI and
frozen local83 scopes differ explicitly; build variation is not the pipe change.
Stock-plus-eleven limits, unknown global resources and unmeasured physical hosts
prevent a general parity/adoption conclusion.

matches its byte count and hash; receipt/manifest binding alone is insufficient.
