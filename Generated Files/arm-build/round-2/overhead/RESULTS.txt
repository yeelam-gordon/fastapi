BEST VERIFIED RESULT
One fresh official-environment Python process builds the COMPLETE sdist using
PDM 2.5.0, selects wheel inputs FROM that completed archive, extracts them to a
fresh owned directory, and invokes a fresh public PDM build_wheel hook there.
Selection is computed inside each timed subprocess. No precomputed file list,
prepared metadata or fallback to checkout files.

Five alternating measured trials, after one preparation per alternative:
  refined selective: median 1.953680 s, range 1.864453-1.998070 s
  matched full tar:  median 2.540550 s, range 2.507786-2.566020 s
  reduction: 23.10%; every pair favored selective extraction.
The earlier uv median was 3.006287 s (35.01% higher-relative reduction from uv
to selective), but it was a separate batch, NOT a directly paired comparison.
These are local results, not a reproduction of the CI 2.679 s or Mac 0.730 s.
Parity remains unestablished. The five cross-platform executable-mode script
differences remain unresolved and are NOT waived.

WHY THE SELECTION IS SOUND FOR THIS BOUNDED CONFIGURATION
Installed PDM sources reviewed: base.py Builder._get_include_and_exclude,
_collect_files/get_hooks; config.py BuildConfig; wheel.py get_files,
_get_wheel_data/_write_dist_info; hooks/version/__init__.py; utils.py
is_python_package. Current source commit:
264cbad400c8336057a70b9b6a65bfdb4920321e.
Selector reads pyproject.toml and the file inventory from the completed sdist.
It discovers default top-level Python/stub packages from archive entries,
retains root files and package contents, and applies configured source-includes.
Required metadata inputs checked: pyproject.toml, README.md, LICENSE,
fastapi/__init__.py (file-based dynamic version). Package/data files are kept.
It rejects extra PDM build keys, custom hooks, installed hook entry points,
src-layout, unsupported dynamic fields/version sources, wildcard source-only
patterns and metadata inputs outside its selected set. No general-purpose
packaging frontend is claimed. These rejection branches were inspected, not
separately exercised as a unit-test suite in this bounded experiment.
The extracted tree is the wheel hook's cwd; all materialized inputs originate
from the sdist. Standard PDM generates wheel metadata anew.
