reports ModuleNotFoundError: No module named 'pdm'. Exact failed command,
return code and raw stderr are retained in ziptools-run/verification.json and
unmodified-wheel-probe.stderr.txt.
The bounded alternative repacks the TOOL wheel with explicit directory entries.
No namespace module injection, metadata monkeypatch, global sys.path change,
or project input cache. Only the derived tool ZIP is prepended to child sys.path.
Source ZIP preserves every original source/resource/dist-info member byte.
Bytecode ZIP additionally contains optimize=0 legacy .pyc siblings with valid
source timestamps. Original sources remain available for normal fallback.
Actual backend, sdist and wheel imports resolve to .pyc; verification asserts
the backend bytecode origin. Both variants use native base Python -S.
